FINAL YEAR PROJECT · NLP

Scam SMS Detection

My ongoing final year project uses NLP and machine learning to distinguish scam and legitimate SMS in English and Bahasa Melayu.

Python NLP TF-IDF Machine Learning
CASE FILE / 01

Read Between the Texts

Bilingual SMS Analysis
  1. 01

    The problem

    Scam texts can imitate familiar services to make a request sound genuine. I built this project to help readers spot suspicious SMS in English and Bahasa Melayu.

  2. 02

    How it works

    The system cleans the message and uses TF-IDF to give more weight to terms that help distinguish it from other messages. A support vector machine (SVM) then classifies the SMS.

  3. 03

    What users see

    The interface shows a scam or legitimate label, a confidence score and highlighted words that help explain the prediction.

CASE FILE / 08 · ROUTE OPTIMIZATION

UITM SHAH ALAM · COURSEWORK

A shorter route around campus.

The project uses Ant Colony Optimization to compare different orders for visiting campus shuttle stops. Three experiments tested how changes to the algorithm settings affected the shortest route found.

EXPERIMENT AT A GLANCE

Shortest route found
13.70 km
Selected configuration
Experiment 2

HOW THE ROUTE SEARCH WORKS

  1. 01
    Build routes

    Simulated ants visit the shuttle stops in different orders.

  2. 02
    Reinforce shorter routes

    Pheromone updates guide later iterations toward connections found in shorter routes.

  3. 03
    Compare experiments

    Experiment 1 found a 14.11 km route. Experiment 2 reduced it to 13.70 km, and Experiment 3 matched that distance.
